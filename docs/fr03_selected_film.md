# 촬영 구역에서 선택한 필름 연결

창문 크기와 위치를 입력한 뒤 필름 격자에서 선택한 행·열을 `windowDimensions.captureModule = {row, col}`로 공간에 저장한다. 행은 실내에서 창을 바라봤을 때 위에서부터, 열은 왼쪽부터 시작하는 0 기반 인덱스다. 창문 크기를 수정하면 기존 선택을 해제한다.

PC와 모바일의 창문 입력 화면은 같은 선택 필드를 사용한다. 모바일에서 바로 촬영을 시작하는 경우에도 공간 저장이 성공한 뒤 촬영 화면으로 이동한다.

## 촬영 연결

- `GET /api/scenes/{scene_id}/capture-marker/targets`는 기존 `windows`와 함께 저장된 선택이 있으면 `selected_target`을 반환한다. 내용은 `window_id`, `module_row`, `module_col`이다.
- 촬영 화면은 저장된 선택을 불러와 표시한다. 같은 필름을 다시 고르지 않는다. 선택이 없는 기존 공간은 종전 촬영 화면의 필름 선택을 유지한다.
- 촬영 시작 요청이 필름 정보를 생략하면 서버가 저장된 선택을 사용한다. 명시적으로 보낸 값이 저장된 선택과 다르면 409로 거부한다.
- 서버는 선택한 모듈의 중앙에 무작위 ID의 60cm 마커를 배치한다. 응답의 `film_module`, `board`, `marker.T_ENU_marker`가 촬영 및 측정의 기준이다.
- 진행 중인 촬영과 저장된 선택이 달라지면 기존 세션 조회·측정을 거부한다. 이전 촬영을 종료한 뒤 새로 시작한다.

필름은 1m 정사각형이며, 마커 중심은 창 왼쪽 아래 기준 `(col + 0.5, 창 높이 - row - 0.5)` m다. 바닥으로부터의 높이는 창 아래 높이를 더한다. 공유 FR06 Scene 형식은 변경하지 않는다.

노트북 화면이나 인쇄물로 촬영하는 테스트 절차 및 실측 마커 크기의 테스트 전용 지원은 이 변경의 범위에 포함하지 않는다.
