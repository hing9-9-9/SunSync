# 촬영·측정 결과 연결

## 필름 선택

촬영 시작 화면은 `GET /api/scenes/{scene_id}/capture-marker/targets`에서 창별 완전한 1m 모듈의 행·열 수를 받는다. 사용자는 창과 필름 행·열을 선택한다. 화면은 1부터, 요청의 `module_row`, `module_col`은 0부터 센다. 60cm 단일 마커는 선택 모듈의 중앙에 표시한다. 마커 크기·수동 중심 입력은 제공하지 않는다.

진행 중 촬영은 기존 세션을 재사용한다. 필름을 바꾸려면 촬영을 종료한 뒤 다시 선택한다. 현재 표시 경로는 가상 필름이며 실제 MCU 연결은 별도다.

## 측정 형상과 표준 모델

직사각형·원은 4점, 타원은 6점, 단순 다각형은 3~16개 꼭짓점을 사용한다. 선택한 도형의 적합 결과와 수평 여부를 수신 서버에서 다시 검증한다. 측정 응답의 `surface.kind`, `surface.outline_board_m`, `surface.bounding_box`는 상판 종류·실제 외곽·표준 모델용 경계상자를 구분한다.

FR-06 관측은 `tabletop_shape`와 원본 측정점, 다각형의 `tabletop_outline_enu_m`을 보존한다. 화면과 가림 계산은 직육면체 표준 모델을 사용하므로 원·타원·오목 다각형의 빈 부분도 경계상자에 포함될 수 있다. 실제 세부 형상 복원은 아니다.

## UI와 공통 Scene

가구의 `yaw`는 ENU 동쪽 기준 반시계 방향 각도이며 평면 화면에서는 반대 부호로 회전한다. `width`, `depth`는 회전 전 모델 치수다. `baseHeight`는 설치 바닥 높이다. `serverId`는 측정 가구의 공통 Scene 식별자를 유지한다.

2D·3D 표시, 보호면, 그림자와 겹침 검사는 회전을 반영한다. 90도 회전 후 방 밖으로 나가거나 다른 가구와 겹치면 저장을 거절한다. 이름만 변경한 경우 기존 측정 관측을 유지하고, 치수·위치·각도를 수동 변경한 가구에는 기존 관측을 측정 근거로 재사용하지 않는다.

## 기준 변경

동일한 기준에서는 가구를 추가하거나 이름을 바꿔도 마커와 보정 정보를 유지한다. 측정된 가구가 있는 공간의 방·창·방위·위치 기준 변경은 409로 거절하며 새 공간에서 다시 측정하도록 안내한다. 측정 관측이 없는 공간에서 기준을 바꾸면 기존 마커·보정을 폐기한다. 자동 좌표 재정합이나 과거 버전 탐색 기능은 제공하지 않는다.

합성 관측과 저장 왕복 검사는 계약·좌표 계산을 검증한다. 실제 휴대폰 촬영 정확도, 필름 대비·반사, MCU 표시와 실시간 재촬영 안내의 효과는 현장 검증이 필요하다.
