# 계정 기반 측정 흐름

사용자가 웹·앱에 같은 계정으로 로그인한 제품 흐름을 전제로 함. 내 공간에서 연결 코드 입력 없이 작업 표시. 웹에서 측정 요청 → 서버에 지속 작업 저장 → 앱의 내 공간에 측정 대기/촬영 시작 → 결과 저장 → 웹 측정 완료/도면 확인. QR은 바로 열기 선택 기능. 사용자가 접속 주소를 입력하는 UI는 제거.

`/api/ui/measurements`에서 작업 생성·목록, `/{token}`에서 상태·공간 조회, `/connect`에서 촬영 시작, `/complete`에서 저장 버전 확인 후 완료 처리. 중복 활성 요청은 기존 작업 반환. 공간 목록에서 공간과 작업 상태를 3초마다 갱신.

기존 코드 연결 API는 과거 호환 코드로 남아 있으나 UI에서는 사용하지 않음. 인증과 계정별 접근 제어는 서버에 구현되어 있다: 연결·측정 token은 그 공간을 만든 계정만 쓸 수 있고 다른 계정은 404를 받는다 ([auth.md](auth.md)). 로그인이 꺼진 개발 서버에서는 격리 없이 동작. 실제 기기 연결에는 동일한 HTTPS 배포 환경 필요. `VITE_PUBLIC_URL`이 있으면 선택 QR 링크에 사용하며 localhost에서는 QR 숨김. 실제 ArUco/SLAM 미연결 상태는 유지.
