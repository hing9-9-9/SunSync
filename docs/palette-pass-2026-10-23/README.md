# 배색·모바일 여백 조정 — 2026-10-23

사용자 요청에 따라 배경과 정보 대비를 개선. 기존 기능·데이터·카드 최대 폭 유지.

참고:
- Awwwards Superlist SOTD (https://www.awwwards.com/sites/superlist): 공식 페이지와 수상작 스크린샷 확인. 한정된 색을 큰 영역/주 동작/기본 정보로 구분하는 방식을 참고. 원작의 빨강은 도입하지 않고 기존 SunSync 보라색 유지.
- GDWEB 토스 Winner Prize (https://www.gdweb.co.kr/sub/view.asp?str_no=27458), 실제 toss.im 화면: 밝은 바탕, 짙은 정보, 시각 콘텐츠와 페이지 바탕의 구분 참고.
- GDWEB Two More Steps (https://www.gdweb.co.kr/sub/view.asp?Txt_fgbn=5&str_no=27874): 화이트 기반 선정 사례로 확인. 색상 토큰은 복제하지 않음.
- 이번에도 기존 Refero 스킬의 reference-lock 방식 유지. 실시간 Refero는 앞선 구독 오류로 사용 불가.

결정:
- 웹 홈: 흰 기본 바탕 + 옅은 보라 도면 영역/소개 구간 + 회색 사용 순서 구간 + 기존 짙은 마지막 CTA.
- 웹 내부: #f3f3f8 바탕, 흰 입력·설정·가이드 면. 기본 글씨 #24232c, 보조 글씨 #55515f, 주요 경계 #b8b3c2. 선택·주 동작은 기존 보라색.
- 모바일: 본문·제목·플러스 행의 좌우 인셋 24px, 350px 이하 20px. 하단 메뉴 56px(+safe area), 아이콘20px/글씨14px, 터치영역 최소44px. 하단 액션·촬영·토스트 오프셋 동시 조정.

검증:
- 프런트엔드 빌드 성공.
- 390×844 모바일 내 공간/상세, 메뉴56px·액션바 끝788px=메뉴 시작788px로 겹침 없음.
- 1440×1000 웹 홈/내 공간/가이드 배색, 가로 넘침 없음 확인.
- UI 디자인·배치만 수정했고 서버 저장/푸시하지 않음.
