# FR-03 / FR-05 공용 단일 마커 규격

2026-11-06 실험 결론: 이번 단일/4개 마커 비교에서 4개 구성의 유의미한 정확도 개선을 확인하지 못했다. 실제 필름의 제어 해상도에 맞춰 단일 마커를 채택한다. 이 결정은 단일 마커의 5% 정확도 달성을 입증하지 않는다.

| 항목 | 규격 |
|---|---|
| 필름 전체 | 1m × 1m, 10행 × 10열 |
| 셀 한 변 | 0.1m |
| ArUco | DICT_4X4_50, ID 0 기본값 |
| 마커 구성 | 내부 4×4 비트 + 1셀 검정 테두리 = 6×6셀 |
| 마커 검정 외곽 | 0.6m × 0.6m |
| 시작 셀 | 0부터 세는 (row=2, col=2) |
| 마커 주변 영역 | 사방 0.2m |

보드 ID는 공간 안의 기준 설치를 식별한다. 사용자마다 다른 패턴을 만들 필요는 없다. 필름 API는 기존 다른 ID도 지원하지만 현재 공용 앱 측정 경로는 ID 0을 사용한다. 다른 ID 또는 크기로 등록된 필름은 측정 전 명시적으로 거절하며 60cm로 잘못 해석하지 않는다.

## 연결 계약

- 측정 Board 기본값: `ids_by_row=[[0]]`, `marker_side_m=0.6`, `gap_x_m=gap_y_m=0`, `border_bits=1`. 다른 실측 크기의 단일 마커도 명시적으로 입력할 수 있다.
- 기존 2×2 실험 입력은 네 ID와 간격을 명시한 경우에만 지원한다. 배치가 생략된 새 요청은 단일 마커로 해석한다.
- 측정 보드 원점: 검정 외곽 왼쪽 위, x 오른쪽, y 아래쪽, z 화면 안쪽.
- FR-05 / FR-06 마커 원점: 마커 중심, x 오른쪽, y 위쪽, z 실내 방향. 중심 이동과 y/z 반전을 함께 적용한다. 변환 행렬은 row-major이며 회전의 각 열이 로컬 축의 ENU 방향이다.
- 프런트는 등록된 창 마커의 실제 `T_ENU_marker`를 우선 사용한다. 창 마커가 없는 출력물 테스트는 사용자 확인 창 위치를 사용하며, 저장된 마커 크기가 0.6m가 아니면 측정을 중단한다.
- 과거 4개 보드의 브라우저 보정 캐시는 새 키를 사용해 재사용하지 않는다. 서버 registration_calibration도 새 보드 기준으로 다시 등록해야 한다. 기존 관측/좌표를 새 기준으로 조용히 재해석하지 않는다.

## 품질과 보정

마커 한 개의 네 코너로 PnP를 수행한다. 평면 자세 모호성·재투영 오차·반복 편차 기준을 완화하지 않는다. 자동 카메라 설정은 설정된 마커 전체를 포함한 12~30개 서로 다른 위치/각도 관측을 사용하며, 화면 커버리지·기울기·파라미터 불확실성·별도 검증 시점의 잔차를 확인한다. 단일 마커 보정의 실기기 정확도는 별도 검증 대상이다. 기기 보정값을 얻지 못하거나 자동 설정이 불안정하면 임의의 카메라 값을 사용하지 않는다.

필름의 불투명도 1/0은 인쇄물의 검정/흰색과 물리적으로 같지 않다. 실제 필름의 대비·반사·배경·주변 셀 상태는 기기 실험에서 확인해야 한다. 현재 필름 API는 마커 영역 바깥의 상태를 보존한다.

촬영은 사용자가 선택한 도형별 지점에서 수행한다. 이번 변경은 마커 규격과 연결 계약만 변경한다. 다중 도형의 FR-06 내보내기 확장, 연사·가중치 공동 최적화는 별도 작업이다.
