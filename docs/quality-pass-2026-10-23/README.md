# SunSync 제품 UI 정리 — 2026-10-23

기존 디자인을 유지한 사용성 개선. 어워드 충족·수상 여부를 인증하는 문서는 아니다.

## 참고 방향과 결정

Refero 스킬을 읽고 검색을 시도했으나 NO_SUBSCRIPTION으로 실시간 자료를 가져오지 못했다. 스킬의 craft-details/typography 자료, 사용자 지정 레퍼런스와 현재 제품 화면을 기준으로 진행했다.

| 결정 | 근거 | 적용 범위 |
|---|---|---|
| 흰 웹 캔버스·보라색 주요 동작 유지 | 기존 SunSync, 사용자 제약 | 기존 랜딩 유지, 내부 작업 화면 정리 |
| 작업 제목·메타데이터·저장 동작 구분 | Canva의 제작 도구 컨텍스트, 기존 오른쪽 설정 패널 | 공간 이름을 상세 제목으로, 웹 편집 저장 바 sticky |
| 주 동작과 보조 동작 위계 | Dropbox의 주요/보조 진입 구분, 기존 SunSync | 저장 보라색, 보조 동작 외곽선·hover |
| 모바일 작업 집중과 간결한 정보 | Omio 앱 소개의 작업 중심 구성, 스킬 typography | 기존 배경 유지, 제목·섹션·본문·상태 크기와 대비 정리 |
| 숫자 입력과 오류 연결 | 스킬 craft-details, 실제 잘못된 치수 입력 점검 | NumberField 공용화, aria-describedby, 오류 시 저장 비활성화 |
| 선택 시 글씨 위치 유지 | 사용자 요청 | aria-pressed/current, 선택 배경·테두리만 변경 |
| 도면 문자 가독성 | 실제 390px 화면 관찰 | SVG 변환 비율로 약 13px 유지, 자유 영역의 긴 이름은 폭에 맞춤 |
| 스크린리더 중복 제거 | 실제 필름 1,400칸 DOM 관찰 | 각 칸은 시각적 툴팁 유지, 접근성은 전체 상태로 요약 |

참고: https://www.dropbox.com/ · https://www.canva.com/ · https://www.omio.com/apps

## 확인

- 앱 390×844: 공간 목록→상세→편집→치수 0 입력 시 필드/화면 경고→가이드 이동 저장 확인→저장하지 않고 이동 확인. 서버 데이터 저장하지 않음.
- 앱 320×740: 공간 목록/상세의 가로 넘침 없음 확인.
- 웹 1440×1000: 상세→편집→종료, 제목·저장 바·도면/오른쪽 설정 패널 확인. 가로 넘침 없음.
- 수치 입력 UI를 두 셸이 같은 컴포넌트로 공유.
- 프런트엔드 기존 기능 테스트 40개, 빌드, lint 확인. lint의 기존 DeviceHandoff set-state-in-effect 경고는 범위 밖으로 남김.
- 로그인·카메라의 실제 외부 계정/실물 QR 인식 완성도를 검증한 것은 아님.
